# Dee Kitchen Tasta 🍲

**Authentic Calabar flavours, cooked fresh and served with love.**

Dee Kitchen Tasta is a modern, responsive food ordering website designed to showcase authentic Calabar cuisine. Customers can explore the menu, view available portions and prices, build their orders, and send them directly to the kitchen through WhatsApp.

## ✨ Features

- **Modern Homepage:** Welcoming hero section, brand introduction and menu highlights.
- **Digital Menu:** Browse Pepper Soups, Soups and Stews.
- **Portion Selection:** Choose from available food portions and prices.
- **Interactive Order Basket:** Add items, update quantities and calculate order totals.
- **WhatsApp Ordering:** Send selected items, quantities, customer details and order totals directly to WhatsApp.
- **Brand Story:** Dedicated section introducing Dee Kitchen Tasta.
- **Contact Information:** Phone, WhatsApp, Instagram and business address.
- **Responsive Design:** Optimised layouts for mobile, tablet and desktop screens.
- **SEO Foundation:** Structured web export and support for search-engine metadata.

## 🚀 Getting Started

### Prerequisites

- Node.js (LTS)
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/dee-kitchen-tasta.git
```

Navigate into the project:

```bash
cd dee-kitchen-tasta
```

Install dependencies:

```bash
npm install
```

### Run Locally

Start the Expo development server:

```bash
npx expo start --web
```

The website will be available in your browser.

## 📦 Production Build

Generate the production web build:

```bash
npx expo export --platform web
```

Expo generates the production files inside the `dist/` directory.

## ☁️ Deployment

The project is configured for deployment on [Vercel](https://vercel.com/).

### Vercel Configuration

- Framework Preset: Other
- Build Command: `npx expo export --platform web`
- Output Directory: `dist`
- Install Command: `npm install`

The project includes a `vercel.json` configuration file.

Connect the GitHub repository to Vercel to enable automatic deployments whenever changes are pushed to the main branch.

## 🛒 Ordering System

Dee Kitchen Tasta uses WhatsApp as its ordering channel.

Customers can:

1. Browse the available menu.
2. Select their preferred food portions.
3. Add multiple items to their basket.
4. Adjust item quantities.
5. Enter their name and special requests.
6. Send their order directly to the business through WhatsApp.

**Note:** This version does not include online payments, a backend database, an admin dashboard, automatic stock management or order tracking. Delivery and pickup arrangements are confirmed directly through WhatsApp.
